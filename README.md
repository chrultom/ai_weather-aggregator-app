# AI Weather Forecast Aggregator

**Pure vibe coding: Not a single line was written manually.**
This project is an experimental implementation where 100% of the code was generated by AI (Cline).

## Features
- ⛅ **Multi-Model Consensus:** Aggregates and compares long-term forecasts (7–14 days) from leading numerical weather prediction models: Open-Meteo Best Match, MET Norway (`metno_seamless`), ECMWF IFS (0.25°), NOAA GFS Seamless, DWD ICON, and 7Timer!.
- 🌡️ **Temperature Ensemble:** Daily maximum, minimum, and mean temperatures with shaded inter-model uncertainty envelopes.
- 🌧️ **Rain & Precipitation Forecasting:** Daily rainfall accumulation (mm) across all models, consensus daily rainfall, and peak intensity alerts.
- ☁️ **Cloudiness & Sky Cover:** Daily mean cloud cover percentages (0–100%) mapped to intuitive sky conditions (☀️ Sunny, ⛅ Partly Cloudy, 🌥️ Mostly Cloudy, ☁️ Overcast, 🌧️ Rainy).
- 🌐 **Free Global Geocoding:** Search any city worldwide using Open-Meteo Geocoding API with OpenStreetMap Nominatim fallback and location disambiguation.
- 📈 **Interactive Visualizations:** Comparative line and grouped bar charts powered by Plotly with hover tooltips, zoom, and trace toggling.
- 📋 **Comparative Data Table & CSV Export:** Unified tabular view with individual model breakdowns and 1-click CSV download.
- 📅 **Table View Subpage:** Dedicated subpage displaying all models on one screen with 4 flexible modes:
  - 🏆 **Master Ensemble Table:** Unified consensus table displaying daily weather symbols, max/min temps, rain, and cloud cover.
  - 📊 **All Models Comparison Matrix:** Side-by-side comparison across all models for every calendar day on one screen.
  - 🔍 **Daily Cross-Model Inspector:** Day-by-day analysis comparing individual model forecasts and deviations from consensus.
  - 📑 **Individual Model Tables:** Complete forecast tables for each provider (MET Norway, ECMWF, GFS, Best Match, ICON, 7Timer).
- 🔑 **100% Free & Keyless:** No API keys or registration required.

## Technology Stack
- **Framework:** [Streamlit](https://streamlit.io/)
- **HTTP & API Requests:** [Requests](https://requests.readthedocs.io/)
- **Data Handling:** [Pandas](https://pandas.pydata.org/) & [NumPy](https://numpy.org/)
- **Charts & Visualization:** [Plotly](https://plotly.com/python/)
- **Weather Data Providers:** [Open-Meteo API](https://open-meteo.com/), [MET Norway](https://www.met.no/), [7Timer! API](http://www.7timer.info/)
- **Testing:** Python `unittest`

## Getting Started

### Prerequisites
- [Python](https://www.python.org/) (Version 3.10 or higher recommended)
- [pip](https://pip.pypa.io/) (included with Python)

### Installation & Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/chrultom/ai_forecast.git
   cd ai_forecast
   ```

2. **Create and activate a virtual environment:**
   ```bash
   # Unix/macOS
   python3 -m venv .venv
   source .venv/bin/activate

   # Windows (PowerShell)
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

3. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Run Tests:**
   Verify that all API connectors, geocoding, and ensemble calculations work:
   ```bash
   python -m unittest test_app.py
   ```

5. **Start the Application:**
   Run the Streamlit application:
   ```bash
   streamlit run app.py
   ```

6. **Open the App:**
   Navigate to [http://localhost:8501](http://localhost:8501) in your web browser.
